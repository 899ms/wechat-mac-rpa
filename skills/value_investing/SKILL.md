# 价值投资分析 Skill

## 一句话摘要
提到具体股票代码、标的名称或明确要求分析股票/板块时启用。

## 触发条件

以下情况触发：
- 用户提到股票代码（如 600519、hk00700、AAPL）
- 用户明确问"某股票怎么样""分析一下""能不能买""还能拿吗""能加仓吗"
- 用户点名要求分析王芊常关注的具体标的：腾讯、拼多多等

**不触发**：
- 泛泛聊市场/行情/板块（"今天大盘咋样""中概被带起来了""我回本了"）→ `casual_chat` / `group_banter`
- 群里随口提到某个板块但没人要求分析 → `group_banter`
- 明显的财经知识问答（"市盈率是什么"）→ `answering_questions`

## 分析流程

### 硬性规则（先执行）
- 没有拿到 `stock_query` 数据前，不凭记忆或感觉给判断。
- 必须给出明确判断：买入/持有/观望/卖出。
- 必须给出目标价区间和止损价。
- 必须有一句话风险提示。
- 必须有一句免责声明。
- 绝不推荐具体买卖时机（如"下午 2 点买入"）。
- 不预测短期涨跌。
- 单只股票分析不超过 3 条回复。

### STEP 1: 获取数据
调用 `stock_query(stock_code)` 获取实时行情：
- 当前价、涨跌幅、成交量、换手率
- 市盈率(PE)、市净率(PB)、总市值
- 52周最高/最低（港股）

### STEP 2: 搜索新闻
调用 `web_search(query)` 搜索最新动态：
- "{股票名称} 最新消息"
- "{股票名称} 财报/业绩"

### STEP 3: 综合分析

**基本面（权重 50%）**：
- PE < 15 → 低估，PE > 40 → 高估
- PB < 1.5 → 安全边际高
- 市值是否合理（对比行业龙头）

**技术面（权重 30%）**：
- 涨跌幅 > +5% → 不追高
- 涨跌幅 < -5% → 恐慌盘，观察
- 换手率 > 10% → 活跃，注意风险
- 接近 52 周低点 → 可能有机会

**消息面（权重 20%）**：
- 利好/利空新闻对基本面的实质影响
- 区分一次性事件 vs 长期趋势

### STEP 4: 输出规则
- 给出明确判断：买入/持有/观望/卖出
- 必须给目标价区间和止损价
- 风险提示一句话
- 免责声明一句
- 熟人小群里可用口语化短句，不必每句都带数据；情绪词（"妈的""羡慕"）只在关系近时用。
- **免责声明必须出现**（如"以上纯属个人看法，不构成投资建议"），即使熟人小群也不能省。

## 其他规则
- 熟人小群里可用口语化短句，不必每句都带数据；情绪词（"妈的""羡慕"）只在关系近时用。
